# 一个图块拆分工具

最近在处理 AI 生成漫画和素材图的时候，我遇到一个很麻烦的问题：一整张图里有很多素材、图块，但是想把它们一个个单独导出来，就只能手动裁剪。

我不太想做这种重复劳动，于是做了一个web工具：：**上传一张图，自动把透明背景隔开的多个元素自动拆分。然后逐个预览、选择和导出。**

👉 https://yvanlouise.github.io/Image-Tile-Splitter/

## 核心功能

**找出所有互不相连的非透明区域。**

若满足条件：元素之间是被透明像素隔开的

它可以：

- 自动识别每一个独立图块
- 列出来让你逐个预览
- 一键导出单个或全部图块

## 适合图片类型

目前我主要考虑两类使用场景。

第一类是**透明背景素材图**。

例如一张 PNG 里面有很多道具、角色小人、表情包、图标，只要它们之间是透明区域隔开的，工具就可以自动识别出每个独立图块。

第二类是**提前处理好透明通道的漫画页**。

比如一张 AI 生成漫画，如果你能提前把每个漫画格之间的空隙处理成透明，那么工具就可以把每个漫画格当成独立图块进行识别和导出。

你有一张这样的素材图：

- 背景是透明的
- 上面摆了很多小图（角色、道具、图标等）
- 每个小图之间互不接触

正常流程是：

手动裁 → 导出 → 再裁 → 再导出……

而这个工具的流程是：

上传图片
→ 自动识别所有图块
→ 点选查看
→ 批量导出

中间基本不需要手动裁剪。

## 关于漫画格拆分
<img width="2470" height="1295" alt="屏幕截图 2026-05-05 162107" src="https://github.com/user-attachments/assets/550b8452-f135-4411-ace1-679f7851a83d" />

这个工具**不是一个成熟的漫画分镜识别工具，   一键拆分漫画格的功能并不完善。**

如果你做了下面这种处理：

- 每个漫画格之间是透明的
- 或者格子之间有明确断开

那么工具可以直接把每个格当成一个图块分出来。

推荐的方式是：手动/自动把格子之间处理成透明，再用这个工具拆分，这样结果会非常稳定。
